Web App developed for image enhancement, integrating OpenAI’s image-to-image API for advanced image generation and the Gemini API to create a descriptive title based on the image.

- Implemented Google OAuth authentication and managed a serverless backend using Supabase.
- Designed and styled the front-end with TailwindCSS.
- Gained an introduct to SQL, creating and managing tables in Supabase and defining Row Level Security (RLS) policies.
